Cara Hosting & Bagikan Web Ini Gratis

Aplikasi ini dikembangkan dalam satu file HTML mandiri (Self-Contained). Anda dapat membagikan file ini langsung atau memasangnya di server internet secara 100% Gratis melalui beberapa pilihan berikut:

1. Kirim File Langsung (Tanpa Server)

Simpan kode ini dengan nama index.html. Siapapun dapat membuka file ini di laptop/smartphone langsung melalui browser (Chrome, Edge, Safari) tanpa perlu install server.

2. GitHub Pages (Domain Permanen Gratis)

  1. Buat repositori publik baru di GitHub.com.
  2. Upload file index.html ini ke dalam repositori tersebut.
  3. Buka Settings > Pages, ubah Branch ke main lalu simpan.
  4. Dapatkan Link URL Publik (contoh: username.github.io/hiperbola-3d).

3. Netlify Drop (Hosting Paling Cepat 10 Detik)

  1. Buka app.netlify.com/drop.
  2. Drag & Drop folder berisi file index.html ke halaman browser tersebut.
  3. Web langsung aktif dan Anda mendapatkan link publik seketika!
